## ✨ Features
- Custom typography and layout built using **Jetpack Compose**.
- Responsive vertical layout with centered profile information and bottom-aligned contact details.
- Scalable design matching custom brand specifications.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose / Material3
- **Design Tool:** Figma
